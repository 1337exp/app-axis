# Axis

[English](README.md) · **Русский**

Место, где проект проектируют вдвоём: человек и Claude. Проект это дерево записей с типом (раздел, задача, идея, решение, вопрос, заметка), со статусами, сроками, связями, картинками и журналом. Данные лежат обычными файлами на диске, страница показывает их вживую, а Claude читает и правит их через MCP-сервер.

**Стек:** Vue 3 + TypeScript + Vite, интерфейс на [TaoUI](https://www.npmjs.com/package/@1337exp/taoui), текст записи в [TaoEditor](https://www.npmjs.com/package/@1337exp/taoeditor), i18n из [TaoUX](https://www.npmjs.com/package/@1337exp/taoux). Сервер на Node 22.18+ без зависимостей (TypeScript запускается как есть). Тесты: Vitest.

```bash
npm install
npm run dev         # страница и API на http://localhost:4517
npm run build       # проверка типов и сборка
npm start           # собранная страница и API без Vite
npm run mcp         # MCP-сервер (обычно его запускает Claude Code, см. ниже)
npm test
npm run typecheck
```

## Что умеет

- **Дерево проекта.** Раздел собирает записи в ветку и показывает её прогресс (сделано задач из всех, отброшенные не в счёте). Клик по кружку задачи ведёт её по кругу: не начата, в работе, готова. В строке видно срок (просроченный красным), есть ли текст и картинки, карандаш, если у текста есть несохранённый черновик, и значок «C», если последним запись правил Claude.
- **Доска.** Те же записи в четырёх колонках по статусу (не начато, в работе, готово, отброшено): что в работе сейчас и что дальше. На карточке тип, заголовок, разделы над ней, срок, карандаш черновика и значок «C». Карточку можно перетащить в другую колонку или сменить статус в меню на ней (там статусы названы словами типа записи); клик открывает запись в панели справа. Фильтры по типу (по умолчанию задачи и вопросы) и по ветке запоминаются для каждого проекта.
- **Лента.** Записи со сроком списком по датам: что на когда назначено и что уже опоздало. Не диаграмма Ганта: у записи один срок, без начала и длительности. Секции: просрочено (красным, старые первыми), сегодня, завтра, эта неделя, следующая неделя, дальше месяц за месяцем; в конце свёрнутый запас «Без срока» (задачи и вопросы без срока: напоминание о том, что лежит). Строка: отметка (круг задачи двигает статус, как в дереве), заголовок, разделы над ней, дата с днём недели и подсказка («через 2 дня», «просрочено на 3 дня»); клик открывает запись в той же панели справа, что и у доски. Кнопка с календарём на строке меняет срок, не открывая запись (в журнале остаётся строка). Готовые и отброшенные скрыты, «Показать завершённые» возвращает их в их секции. Те же фильтры по типу и ветке, что у доски, но свои; всё запоминается для каждого проекта. «Сегодня» сдвигается само в полночь.
- **Отмена.** Статус, изменённый одним щелчком или одним перетаскиванием (кружок в дереве или ленте, карточка на доске), и срок, изменённый с кнопки в строке ленты, показывают тост «Название: новый статус» с кнопкой «Отменить»; отмена возвращает прежнее значение тем же сохранением, поэтому в журнале появляется строка. Следующая правка заменяет тост. В открытой записи переключатель статуса и так перед глазами, поэтому тоста у него нет.
- **Быстрый ввод.** Поле под деревом: строка и `Enter`. Знак в начале задаёт тип: `?` вопрос, `!` решение, `*` идея, `#` раздел, `-` задача, `~` заметка; работает и словом (`идея: …`, `todo: …`). Запись встаёт в выбранный раздел или сразу после выбранной записи, так что список набирается сверху вниз.
- **Запись.** Заголовок, тип, статус (слова статуса свои у каждого типа: у решения «Принято», у вопроса «Отвечен»), срок, текст с заголовками, списками, таблицами и кодом. Тип, статус, срок, связи и картинки сохраняются сразу, заголовок при выходе из поля. Текст показывается для чтения (длинный сокращён до примерно 12 строк с «Показать полностью»); «Править» (или двойной клик, или Enter на тексте) открывает редактор, и набранное лежит **черновиком** на сервере, не в записи и не в журнале, пока ты не нажмёшь «Сохранить» (`Ctrl+Enter`: одна строка журнала) или «Отмена» (если черновик отличается, она сначала спросит). Черновик не теряется ни при перезагрузке, ни при выборе другой записи, другого вида или закрытой панели: запись откроется в правке с черновиком, а в строке дерева и на карточке доски виден маленький карандаш. Если текст тем временем изменили (Claude, другая вкладка, рука), страница скажет об этом, «Сохранить» откажет, а окно покажет новый текст и выбор: записать мой, продолжить правку, взять новый. Само ничего не сливается.
- **Картинки.** Вставка из буфера (`Ctrl+V`), перетаскивание или кнопка. Файл называется по хешу содержимого, одна и та же картинка хранится один раз.
- **Связи.** «Зависит от», «потому что», «связано с»; у записи видны и исходящие, и входящие.
- **Журнал.** Каждое изменение: кто (ты или Claude), что, когда и почему; плюс свободные заметки ко всему проекту или к записи. Только дописывается.
- **Строка состояния.** Тонкая строка внизу окна: прогресс открытого проекта, сделано задач из всех, задач в работе, открытых вопросов. В узком окне менее важные числа пропадают.
- **Вживую.** Сервер следит за папкой данных: правка от Claude, из другой вкладки или руками в файле появляется на странице сама.
- Русский и английский, светлая и тёмная тема, адрес записи или вида в строке адреса (`#/проект/запись`, `#/проект/~board`, `#/проект/~board/запись`, `#/проект/~timeline`, `#/проект/~timeline/запись`, `#/проект/~journal`).

## Где лежат данные

Одна папка на все проекты. Порядок выбора: переменная `AXIS_DATA`, затем `"data"` в `axis.local.json` рядом с `package.json` (образец: `axis.local.example.json`; в git файл не попадает), затем `./data`.

```
<данные>/<проект>/project.json
<данные>/<проект>/records/<id>.json     одна запись на файл
<данные>/<проект>/journal.jsonl         строка на изменение
<данные>/<проект>/drafts/<id>.json         несохранённый текст записи: { body, base, at, by }
<данные>/<проект>/assets/<хеш>.png      картинки
<данные>/<проект>/trash/<id>.json       удалённое (ничего не стирается)
<данные>/<проект>/trash/<id>.draft.json черновик удалённой записи
```

Черновик это один файл на запись, в журнал он не попадает. `base` это штамп `updated` записи на момент начала правки: если при сохранении текста у записи уже более новый, сервер отвечает 409 с текущей записью (тот, кто `base` не шлёт, как MCP-сервер, не проверяется). По HTTP: `GET`, `PUT` (`{ body, base }`) и `DELETE` на `/api/projects/<проект>/records/<id>/draft`; при загрузке проекта приходит список id, у которых есть черновик (`drafts`). Claude черновиков не видит, только сохранённый текст.

Файлы можно читать и править руками, класть в git и переносить. Запись с ошибкой внутри не ломает проект: она приводится к верной или пропускается.

## Как подключить Claude

MCP-сервер работает с теми же файлами, поэтому странице не обязательно быть запущенной. Подключить его к Claude Code для всех проектов:

```bash
claude mcp add axis --scope user -- node E:/job/git/app-axis/server/mcp.ts
```

Инструменты: `axis_projects`, `axis_create_project`, `axis_overview` (проект оглавлением), `axis_read` (запись целиком с журналом), `axis_add`, `axis_update`, `axis_link`, `axis_delete`, `axis_journal`, `axis_log` (заметка в журнал), `axis_search`. Текст записи Claude пишет и читает простым текстом с лёгкой разметкой Markdown; в хранимый документ редактора и обратно его переводят функции Markdown из TaoEditor (`markdownToDoc`, `docToMarkdown`, обёрнутые в `src/core/text.ts`). У изменений есть поле `why`: причина попадает в журнал.

Тот же доступ есть по HTTP (`/api/projects/…`, заголовок `X-Axis-By: claude`), а страницу Claude может открыть и посмотреть во встроенном браузере.

## Как устроено

```
src/core/     чистый TypeScript без DOM и Node: модель, дерево и прогресс, колонки доски, лента по срокам, общий фильтр видов, быстрый ввод, текст ↔ документ, журнал
server/       хранилище на файлах, HTTP API с потоком событий, самостоятельный сервер, MCP-сервер, вид для агента
src/app/      состояние страницы, клиент API, живые обновления, адрес, сохранённые фильтры видов, «сегодня»
src/ui/       дерево с быстрым вводом, доска, лента, запись, журнал, окно нового проекта; общее для видов: панель записи, панель фильтров, отметка статуса
src/i18n/     словари ru / en
tests/        ядро, хранилище и HTTP API (на временной папке)
```

Сервер отвечает только этой машине: слушает `127.0.0.1`, отклоняет чужие `Host` и `Origin`, изменения принимает только как JSON.

## Пока нет

Карта на холсте (ещё один вид тех же данных). Перетаскивание записей в дереве мышью (сейчас «Выше», «Ниже», «На уровень выше» в меню строки). Картинки внутри текста. Отмена действий. Вход с другого устройства. Проверено руками в Chromium; Firefox, Safari, сенсорные экраны и узкий экран не проверены. Тестов на компоненты страницы пока нет, только на ядро, хранилище и HTTP API.
